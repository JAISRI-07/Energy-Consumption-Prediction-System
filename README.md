# Energy Consumption Prediction System

## Overview
A machine learning system that forecasts future electricity usage based on historical consumption patterns and relevant features to support better energy management and efficiency.

This project uses `Energy_predictor.py` to preprocess energy usage data, train a predictive model, and generate consumption forecasts.
